{% comment %} Renders one category from the _publications collection. Reads the same collection and the same archive-single.html include the research page uses, so a paper is written once and appears wherever it is called -- there is no second copy to keep in sync. Usage: {% include publication-list.html category="jmp" %} {% include publication-list.html category="working" heading="Selected Work" %} {% include publication-list.html category="jmp" heading=false %} category key from `publication_category` in _config.yml (jmp, working, books, manuscripts, conferences, wip) heading optional. Defaults to the title set for that category in _config.yml. Pass false to render the list with no heading. Renders nothing at all when the category holds no papers, so calling it for a category you have not written yet is harmless. NOTE ON INDENTATION: the HTML below deliberately starts at column zero.
