{% comment %} Job-market block for the homepage: an explicit invitation to get in touch, then references and placement officer. Data comes from _data/jobmarket.yml, except the email address, which is read from `author.email` in _config.yml so it is defined in exactly one place. Every section is conditional. With jobmarket.yml left as shipped (all keys commented out) only the contact line renders, so the page never shows an empty "References:" label waiting to be filled. Usage: {% include job-market.html %} {% endcomment %} {% assign jm = site.data.jobmarket %} {% comment %} Status and invitation share one line, with the address in parentheses. The parenthetical avoids needing a preposition before the address at all, which a colon or a trailing "at" both handled awkwardly. Either half can go missing: with no status the line is just the invitation, with no email just the status. The space between the two sentences is the literal one after `%}` on the second line below.
